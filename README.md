# Berilio Face UI Workspace

Este directorio contendrá las aplicaciones frontend del proyecto Berilio Face.

## Estructura actual

- `apps/admin-dashboard/` – dashboard administrativo.
- `apps/employee-pwa/` – aplicación PWA para los empleados.
- `apps/marketing-site/` – sitio público/marketing.

Cada carpeta está vacía por ahora; sólo contiene un `README.md` con notas iniciales para comenzar.
